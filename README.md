# LavaKit

Плагин наборов для Paper и Purpur 1.21.4. Java 21.

Меню китов с просмотром содержимого, получением по привилегии и покупкой за PlayerPoints. Отдельные админские наборы для кейсов, боевого пропуска и других наград.

Предметы сохраняются со своими флагами, зачарованиями, атрибутами и остальными данными. Выдача командой проходит без сообщений. Если весь набор не помещается в инвентарь, выдача отменяется.

[Скачать плагин](https://github.com/svarcovv/LavaKit/releases/latest)

## Команды

| Команда | Действие |
| --- | --- |
| `/kit` | Меню обычных наборов |
| `/lavakit give <кит> <игрок> [количество]` | Выдать обычный или админский набор |
| `/lavakit add <кит>` | Сохранить инвентарь в обычный набор из конфига |
| `/lavakit admin` | Меню админских наборов |
| `/lavakit admin create <кит>` | Создать админский набор из инвентаря |
| `/lavakit admin view <кит>` | Посмотреть содержимое |
| `/lavakit admin edit <кит>` | Открыть редактор |
| `/lavakit admin delete <кит>` | Открыть подтверждение удаления |
| `/lavakit reload` | Перезагрузить конфигурацию |
| `/lavakit compare` | Сравнить данные предметов в двух руках |

Пример награды: `lavakit give don %player% 1`. Количество означает число полных наборов, по умолчанию - один. Игрок должен быть в сети. Выдача командой не расходует PlayerPoints и не меняет задержку получения.

В редакторе нажатие на предмет в своём инвентаре добавляет его копию в кит. Нажатие на предмет в ките убирает его. Изменения применяются кнопкой «Сохранить».

## Права

- `lavakit.command.kit` - открыть меню, доступно всем.
- `lavakit.admin` - управление наборами, по умолчанию у операторов.
- `lavakit.give` - выдача командой, входит в `lavakit.admin`.

Существующие `config.yml`, `kits` и `cooldowns.yml` продолжают работать после обновления. Админские наборы хранятся отдельно в `admin-kits` и не отображаются в `/kit`. Имена обычных и админских наборов не должны совпадать. Старая команда `/lavakit kit <кит> give <игрок>` также поддерживается.
