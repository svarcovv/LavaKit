# LavaKit

Плагин наборов для Paper и Purpur 1.21.4. Java 21.

Меню китов с просмотром содержимого, получением по привилегии и покупкой за PlayerPoints. Отдельные админские наборы для кейсов, боевого пропуска илм других наград.

[Скачать плагин](https://github.com/svarcovv/LavaKit/releases/latest)

## Команды

| Команда | Действие |
| --- | --- |
| `/kit` | Меню обычных наборов |
| `/lavakit give <кит> <игрок> [количество]` | Выдать обычный или админский набор |
| `/lavakit add <кит>` | Сохранить инвентарь в обычный набор из конфига |
| `/lavakit admin` | Меню админских наборов |
| `/lavakit admin create <кит>` | Создать админский набор из инвентаря |
| `/lavakit admin view <кит>` | Посмотреть содержимое |
| `/lavakit admin edit <кит>` | Открыть редактор |
| `/lavakit admin delete <кит>` | Открыть подтверждение удаления |
| `/lavakit reload` | Перезагрузить конфигурацию |
| `/lavakit compare` | Сравнить данные предметов в двух руках |

Пример награды: `lavakit give don %player% 1`. Количество означает число полных наборов, по умолчанию - один. Игрок должен быть в сети.

## Права

- `lavakit.command.kit` - открыть меню, доступно всем.
- `lavakit.admin` - управление наборами.
- `lavakit.give` - выдача командой, входит в `lavakit.admin`.

Админские наборы хранятся отдельно в `admin-kits` и не отображаются в `/kit`. Имена обычных и админских наборов не должны совпадать.
